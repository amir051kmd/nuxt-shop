# رفع کندی سایت تسبیح

## علت اصلی کندی
هر ۸ عکس محصولات حدود ۳ تا ۴ مگابایت بودند و صفحه در مجموع حدود ۲۸ مگابایت عکس دانلود می‌کرد.
الان هر عکس ۲۰ تا ۳۰ کیلوبایت است (مجموع حدود ۲۰۰ کیلوبایت).

## چرا کارت‌ها با اسکرول بالا و پایین می‌پریدند
کارت‌ها با hover به بالا می‌رفتند (`hover:-translate-y-1`) و عکس بزرگ می‌شد.
هنگام اسکرول با موس، نشانگر ثابت است و کارت‌ها زیر آن حرکت می‌کنند، پس hover مدام روشن و خاموش می‌شد و کارت‌ها می‌پریدند.
این افکت‌های حرکتی حذف شد (فقط رنگ کادر با hover عوض می‌شود).

## بقیه اصلاحات
- بارگذاری تنبل عکس‌ها (lazy) و ابعاد ثابت برای عکس؛ ۴ کارت اول فوری لود می‌شوند.
- افکت‌های blur هدر و پس‌زمینه طبق درخواست شما دست نخورده ماند.
- `content-visibility` برای کارت‌های خارج از صفحه.
- فونت: woff2 + `font-display: swap` + preload.
- کش یک‌ساله برای `/images` و `/fonts`، فشرده‌سازی فایل‌های استاتیک (`compressPublicAssets`) و غیرفعال کردن devtools.
- مسیر import محصولات به `~~/data/products.json` اصلاح شد (مسیر قبلی `../data` به `app/data` اشاره می‌کرد).
- یکی از عکس‌ها در JSON مسیر بدون `/` داشت؛ اصلاح شد.
- کلاس `scrollbar-hide` در Tailwind نسخه‌ی ۴ وجود ندارد؛ در CSS اضافه شد.
- `lang="fa"` و `dir="rtl"` روی تگ html.
